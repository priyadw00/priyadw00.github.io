# Projects 

## Port scanner

Port scanner capable of conducting connect scans, syn scans, and udp scans. User can specify type of scan, order of scan, number of scan, and target in command line. Commands are executed in parallel to speed up scan.

Built in Python. Uses Scapy for packet construction.

[View repository](https://github.com/priyadw00/portScanner)

## iAssist 

An iOS app designed to improve the usability of iOS home screen for elderly users by replacing icons with clearer, more accessible icons. 

Built using Swift. 

Collaborator: Aria Ramanathan

[View repository](https://github.com/ariaramanathan/iAssist)

## Air Quality Alert System
[View repository](https://github.com/SpikeAlerts/SpikeAlerts_0)

## Address Standardization Automation

I wrote this to help an organization I worked for clean up their mail chimp lists. Takes in address data which and normalizes the data, validates the address, and saves it in the standard format. 

Written to work within a google sheet using Google Apps Script. Use the Google Geocoder API to validate addresses. 

[View repository](https://github.com/priyadw00/AddressCleaner)
